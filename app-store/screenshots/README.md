# App Store screenshot replacements

These replace the two Todos screenshots in the App Store listing, which still show the Todos search bar that was removed in build 29.

| File | Replaces | Display type |
|---|---|---|
| iphone-4-todos.png (1320 by 2868) | new-iphone-4-todos.png, the fourth iPhone screenshot | APP_IPHONE_67 (6.9-inch) |
| ipad-2-todos.png (2064 by 2752) | new-ipad-2-todos.png, the second iPad screenshot | APP_IPAD_PRO_3GEN_129 (13-inch) |

They were taken on 2 October 2026 on the iPhone 17 Pro Max and iPad Pro 13-inch (M5) simulators, with the status bar set to 9:41, full signal and a full battery, showing the same Penne alla Carbonara list as the originals. The alpha channel was removed, because App Store Connect rejects screenshots that have one.

Version 1.0.1 was in review with build 27, which still has the search bar, so its screenshots were left alone. Upload these with the first version that ships build 29 or later.
